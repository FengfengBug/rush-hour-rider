# 《午高峰》3D 改造总方案

> **定位**：用 6 天把“可玩的低多边形配送模拟”升级成“有 GTA 镜头感与电影化记忆点的 3D 作品”，不是把 8×8 城市重做成 GTA 规模的开放世界。
>
> **输入**：`F:\OneDrive\Desktop\ew.md` 的六步 AI 辅助 3D 开发方法；`perspective-illusion` skill 的公开 SKILL.md；GTA V/VI 的第三人称镜头语法；当前项目可玩基线。
>
> **时间**：2026-11-24 – 11-29；11-27 部署 v1；11-30 中午前交卷。polish1–6 已完成，本方案是在可玩主干上的新阶段，不重做订单、城市与账本。

## 0. 一句话结论

**不追 GTA 的“规模与写实”，只抄 GTA 的“镜头、密度、光影、任务语法”；再用透视错觉做 2–3 个 hero moment。**  
现有项目缺的不是系统，而是“看起来像大作”的镜头与城市生活感；6 天只做这一件事。

## 2. 当前基线：为什么 6 天够用

- 8×8 城市约 720m×720m，256 栋合批建筑、26 个地标、6 处换电、49 个红绿灯、28 辆巡航车。
- 1440×900 约 165 FPS、84 draw calls、561k 三角形、40k 实例；生产包约 326KB gzip。
- 已有完整闭环：抢单 → 骑行 → 取餐 → 进楼/门禁 → 送达 → 事件 → 结算 → 算法时间账本 → +5 分钟反事实 → PNG 战报。
- 结论：**改造是“表现层升级”，不是“系统重建”**。城市、订单、账本、手机、天气都保留，只换镜头、密度、光影和任务包装。

## 3. 四层改造 + 一个核心

### 核心：配送闭环不动
任何视觉改造都不能破坏“光柱取送、倒计时、事件选择、账本结算”。每轮改完必须能完整跑一局。

### 第一层：镜头电影化（GTA 感的第一来源）
- 默认越肩追尾：略偏右肩、更低机位、更近景深，转弯时镜头滞后半拍。
- 速度 FOV：冲刺时轻微广角拉伸，刹车时回收；不做剧烈晃动。
- 转角 swing：进入路口/胡同时镜头绕外角摆过去，先“平面”后“展开”。
- 开场/收工：短促的电影化推拉 + 标题卡，不播长 CG。
- 镜头碰撞、室内切换、自由观察、拍照模式全部保留。

### 第二层：城市密度与尺度错觉（GTA 感的第二来源）
- 不加地图，加“生活层”：行人、电动车、街边摊、塑料凳、遮阳棚、霓虹灯箱、垃圾桶、锥桶、停放车辆。
- 用**重复元素在不同深度**堆出尺度：路灯、招牌、行道树、斑马线在长焦里叠成一面墙。
- 远景天际线用 2–3 层剪影 + 雾带压缩，让 720m 的城市看起来更深。
- 行人/车辆全部 InstancedMesh 或低面数 billboard，控制在预算内。

### 第三层：光影、天气与调色
- 4 套预设：**正午阴天（当前）/ 黄昏金时刻 / 夜雨霓虹 / 清晨薄雾**。
- 天空用 Canvas 渐变 + 手绘云层，不加载 HDRI；黄昏参考《你的名字》的暖紫橙，夜雨参考 GTA 的湿路霓虹。
- 湿路不做真实反射：用高光条、霓虹倒影片、车灯地面光斑和低粗糙度材质“骗”出来。
- 雨：现有雨丝 + 地面涟漪 + 车灯池 + 轻微雾；不靠浓雾遮问题。
- 调色只做轻量 tone mapping / CSS 暗角 / 对比，不上重型 bloom/SSR。

### 第四层：GTA 式任务与交互
- 配送单包装成“任务”：接单时一张短任务卡（编号、商家、送达地、限时），收工一次电影化收尾。
- 手机继续做“叙事 UI”：消息、来电、账单、导航都在手机里，HUD 只留任务标记、收入、时间和手机入口。
- F3 技术面板升级为“导演控制台”：时段、天气、镜头、密度、调色、自动巡游。
- 拍照模式：自由镜头 + 长焦压缩 + 强制透视，可导出 PNG；这是透视错觉在游戏里最自然的落点。
- 自动巡游：标题/等待时 20 秒无缝循环，展示城市、天气与车流，用于路演和录屏。

## 4. 透视错觉：5 个用法，3 个禁用

`perspective-illusion` 的核心不是“滤镜”，而是**长焦压平 → 推拉变焦展开纵深 → 转角先平后立 → 平面期偷偷换深度 → 无缝循环**。

### 用法 1：标题「平面海报 → 3D 城市」
- 相机从约 400m 外、极窄 FOV（长焦）看城市，画面像一张平面插画；3 秒内 FOV 拉开、相机推进，街道纵深“炸开”。
- 用一辆经过的公交车/一阵雨/一块招牌完成循环遮罩。
- 这是评委看到的第一个 5 秒，也是宣传片首帧。

### 用法 2：冲刺 dolly zoom
- 加速时相机后拉、FOV 变宽，骑手大小基本不变，背景被拉长；松开后缓慢回正。
- 幅度克制（FOV 变化 ≤4°），只在冲刺/下坡触发，不做常态。

### 用法 3：转角 swing
- 进入特定路口/胡同时，镜头绕外角摆过 60–90°，新街景先像平面，再展开纵深。
- 只在 2–3 个地标转角触发，不打断操控。

### 用法 4：拍照模式的强制透视
- 长焦压缩 + 低机位，让骑手/外卖箱与远处地标“贴”在同一平面；换机位后露出真实距离。
- 这是“透视错觉”与“送达拍照”玩法的结合点，比纯视频更有游戏性。

### 用法 5：海报与 10 秒宣传片
- 海报/片头用墨线、平涂两色、排线阴影、手绘天空；宣传片用 skill 的模板做 10 秒循环。
- 游戏运行时不必全盘改成日式插画风，避免与 GTA 镜头语言打架。

### 禁用
- 正常骑行全程用长焦/强制透视：会晕、会撞、会看不清光柱。
- 事件弹窗、结算账本用透视错觉：信息可读性优先。
- 为炫技加 dolly zoom：一次一局最多 2 次。

## 9. 评委的 10 秒 / 30 秒 / 3 分钟

- **10 秒**：平面海报裂开成 3D 城市 → 越肩骑行 → 速度 FOV。判断“这是作品，不是 Demo”。
- **30 秒**：行人、车流、霓虹、湿路、手机弹单、任务标记。判断“城市是活的”。
- **3 分钟**：取送闭环、事件选择、算法时间账本、+5 分钟反事实。判断“有表达、有主题”。

> 视觉改造只负责前两段；第三段必须原样保留，不能被镜头/密度破坏。

## 11. 明确不做

- 不引入 Blender/GLB/外部模型/贴图/音频（项目红线）。
- 不做 GTA 规模大地图、写实人体、枪战/警察/犯罪叙事、授权音乐。
- 不重写渲染层、不接物理引擎、不做 SSR/SSAO/重型 Bloom。
- 不新增账号、排行、联机、改装商店等系统。
- 不做完整移动端虚拟摇杆；触屏保持精简三轴。
- 不为了“像 GTA”牺牲配送可读性与 60fps。
